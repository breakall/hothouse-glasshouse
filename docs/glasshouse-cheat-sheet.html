01 / Performance panel

Default page

Wet + Dry: noon = unity for each. *Nominal attack, plus detector response.

Footswitches · Pages 1–4

Left: dynamic swell while active; manual mode dips, then swells after release. A brief manual tap completes the dip.

Right: tap to enable/bypass; hold ≥0.4 s for maximum sag. Latch option changes these behaviors.

Hold both ≥3 s: enter USB firmware flashing mode.

K = knob number on diagram · T = toggle number · Toggle choices below read UP / MIDDLE / DOWN

05 / Presets LEDS: BANK + SLOT

ControlAction
K1Select bank 1–8
K2Select slot 1–16
Left tapRecall selected slot; empty slots do nothing
Right hold ≥1 sSave all four settings pages to selected slot
Left LEDFlashes bank number
Right LEDFlashes slot number; dim = empty

127 slots: banks 1–7 have 16; bank 8 has 15. K3–K6 and T1–T3 are unused on this page.

Save overwrites the selected slot. A save briefly mutes audio; the right LED blinks in acknowledgment. Avoid removing power during a save.

This page replaces the normal footswitch actions. Saved presets persist; ordinary page edits alone do not.

CHANGE PAGE Briefly press both footswitches together, then release both: Performance → Envelope → Options → Automation → Presets → repeat

Knob pickup: after changing pages, recalling a preset or sending MIDI, turn through the stored position before a knob takes control. Toggles take control when physically moved.

Remember: no automatic makeup gain—raise Wet to compensate. Dry also feeds the final limiter / Dusty drive. Startup uses physical Performance controls and default advanced options; recall a preset to restore saved options.
